# HR Analytics Power BI Dashboard
## 📊 Project Overview
This project presents an interactive HR Analytics Dashboard developed using Microsoft Power BI.
The dashboard analyzes employee data to understand workforce distribution, employee attrition, salary slabs, departments, job roles, age groups, gender, job satisfaction, and employee experience.
The main objective of this project is to transform HR data into meaningful visual insights that can help organizations understand employee trends and attrition patterns.

---
## 🎯 Objectives
- Analyze total and active employees
- Measure employee attrition
- Calculate attrition rate
- Analyze employee age distribution
- Analyze employee experience
- Compare attrition across departments
- Analyze attrition by salary slab
- Study attrition by gender
- Analyze job role and job satisfaction
- Understand department-wise employee distribution
---
## 🛠️ Tools & Technologies
- Microsoft Power BI

## 📈 Dashboard KPIs
The dashboard contains the following key performance indicators:
- Total Employees
- Active Employees
- Attrition Count
- Attrition Rate
- Average Age
- Average Experience
---
## 📊 Dashboard Analysis
The dashboard provides visual analysis of:
1. Attrition by Department
2. Attrition by Salary Slab
3. Attrition by Job Role and Job Satisfaction
4. Age Group Distribution
5. Attrition by Gender
6. Attrition Trend by Experience
7. Department-wise Employee Count
---
## 🔍 Key Insights
The dashboard can be used to identify:
- Departments with higher employee attrition
- Salary slabs associated with employee attrition
- Employee distribution across departments
- Attrition patterns across different age groups
- Gender-wise attrition distribution
- Relationship between job satisfaction and attrition
- Experience levels associated with employee attrition
